# AI Student Analytics Project - Streamlit

## Run locally
1. Install Python.
2. Open a terminal in this project folder.
3. Install packages:
   `pip install -r requirements.txt`
4. Start the application:
   `streamlit run app.py`

## Deploy using Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Sign in to Streamlit Community Cloud using GitHub.
3. Choose **Create app** and select your repository, branch, and `app.py`.
4. Deploy.

Note: The notebook creates a synthetic sample dataset of 600 students. It does not use real student records.
